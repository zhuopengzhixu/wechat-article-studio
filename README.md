# 微信公众号文章编辑器（在线版）

一个单文件、零依赖的公众号文章排版编辑器，可直接在浏览器打开使用，也可部署到 GitHub Pages 在线访问。

## 功能
- 84 个排版组件 × 5 套配色 = 420 种样式（框架 / 标题 / 正文 / 重点块 / 互动 / 媒体 / 顶底 / 点赞）
- 一键换肤（墨青 / 靛蓝 / 暖橙 / 雾紫 / 竹绿）
- 智能排版：填主题自动生成「黄金结构」文章骨架
- 选区格式：单独设字号 / 字体色 / 背景色 / 清除格式
- 导入 `.md` 与图片，撤销重做，自动保存（localStorage）
- 导出纯内联 HTML（兼容公众号粘贴）、导出 `.md`、原生「另存为」保存

## 使用
直接用浏览器打开 `index.html` 即可。所有数据仅存本地，不上传任何服务器。

## 部署
本仓库已开启 GitHub Pages，根目录 `index.html` 即为站点入口。
